Digital Bookshelf API

A RESTful API for managing a digital collection of books. Create, view, update, and delete book records using the API endpoints below.

View Books API

API Endpoints

POST

/api/books

Create a new book.

GET

/api/books

Retrieve all books.

GET

/api/books/:id

Retrieve one book by ID.

PUT

/api/books/:id

Update an existing book.

DELETE

/api/books/:id

Delete a book from the collection.

Built with Node.js, Express, MongoDB, and Mongoose.
